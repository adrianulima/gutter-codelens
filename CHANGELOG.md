# Gutter CodeLens Change Log

All notable changes to the "gutter-codelens" extension will be documented in this file.

## 0.2.0

- **Configurable debounce delay**: Adjust how quickly gutter icons update while typing via `gutterCodelens.debounceMs` setting
- **CodeLens limit control**: Set maximum number of CodeLenses to display per file with `gutterCodelens.maxCodeLenses` setting
- **Better performance**: Faster loading and updating of gutter icons

## 0.1.0

- Initial release
